# TinyAgent 0.1.0 Preview 3

비공개 개발 프리릴리즈입니다. 기존 개발 APK와 같은 패키지·서명을 사용합니다.
업데이트할 때 기존 앱을 삭제하지 마세요. versionCode 2입니다.

## 바뀐 사용 흐름

- 세션을 옆으로 밀면 고정·삭제가 나타납니다. 삭제 후 6초 동안 되돌릴 수 있습니다.
- 길게 누르면 여러 세션을 선택할 수 있습니다. 일괄 삭제는 개수를 확인합니다.
- 프로젝트 열기에서 `/workspace`에 폴더를 만들 수 있습니다. 같은 이름의 기존 폴더는 보존합니다.
- 프로젝트 목록에서 삭제해도 실제 폴더와 대화는 삭제하지 않습니다.
- 작업 파일은 대화의 파일 액션으로 열기·저장·공유하며, APK는 설치 액션을 제공합니다.

## 사용

설치 → 환경 준비하기 → 대화 시작하기 → 설정의 공급자 연결 → 모델 선택 순서입니다.
Stock의 Fedora와 OpenCode는 앱 UID로 실행하며 ADB 연결이 필요하지 않습니다.
Developer·Root는 별도 권한 확장입니다. 준비 중에는 앱과 알림의 진행률을 확인하세요.

## 검증 기록과 제약

정확한 후보 해시와 실기기 결과는 `PRERELEASE-3-VALIDATION.md`에 기록합니다.
이 프리릴리즈는 전체 정식 릴리즈의 3회 종합 검증을 통과했다는 뜻이 아닙니다.

- 화면 꺼짐 시험은 짧은 잠금 구간의 로컬 실행·복귀 검사입니다. 장시간 Doze와 모든 기기의 절전 정책은 검증되지 않았습니다.
- 화면 꺼짐 중 외부 다운로드 속도 저하가 이전 시험에서 관찰됐습니다. 정상 속도를 보장하지 않습니다.
- 런타임을 켜 두면 CPU 잠금을 유지하므로 배터리 사용이 늘어납니다. 작업 환경에서 로컬 백엔드를 중단할 수 있습니다.
- OpenAI OAuth/Luna 응답·도구 실행은 이전 후보에서 검증했습니다. 모든 공급자와 인증 갱신 방식의 전수 검증은 미완료입니다.
- dnfast의 캐시 삭제 수정은 별도 실기기 검증을 통과했지만, 일반 에이전트 명령 경로 통합과 dnf5 비교·6개 앱 빌드는 미완료입니다.
- 런타임은 현재 Termux PRoot 기반입니다. 자체 Preroot 전체 구현, 전용 정식 서명, 새 후보의 완전한 폰 자체 빌드는 정식 릴리즈 전 남은 작업입니다.

## 진단

작업 환경 → 진단 정보에서 준비 상태와 오류를 확인합니다. 백엔드 로그는 앱 비공개 `files/linux/backend.log`입니다.
보고할 때 APK 버전, 수행한 동작, 오류 메시지를 포함하고 API 키·OAuth 토큰은 보내지 마세요.
빌드·의존성 절차는 `UPSTREAM.md`, `SELF-BUILD.md`, `scripts/self-build-complete-fedora.sh`를 참고하세요.
