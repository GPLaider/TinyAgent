# TinyAgent 0.1.0 Preview 4 candidate

비공개 개발 프리릴리즈 후보입니다. 게시 전 실기기 회귀 검증 중입니다.
versionCode 3, versionName 0.1.0-preview.4.
기존 개발 APK와 같은 패키지·서명을 사용하며 OAuth·세션·작업공간을 보존하는 업데이트를 검증합니다.

변경:
- dnfast의 이미 설치된 패키지 요청을 정상적인 변경 없음 결과로 판정합니다.
  종료 코드, 최종 JSON 및 작업 종류가 모두 일치해야 성공입니다.
- SDK 압축 해제에 검증된 tar.gz 입력을 지원합니다.
- dnfast 진단의 Android 11~13 비호환 API 호출을 수정했습니다.
- Pacman ARM 빌드 실행 절차, 소스 커밋, 실패 로그와 산출물 해시 수집을 추가했습니다.
- 화면 꺼짐 검증 도구가 두 기기의 포트를 분리하고 결과 파일을 덮어쓰지 않습니다.

사용: 설치 → 환경 준비하기 → 대화 시작하기 → 공급자 인증 → 모델 선택.
Stock Fedora는 앱 권한으로 실행합니다. Developer 페어링과 Root는 선택 사항입니다.
작업공간 파일 경로를 눌러 설치·보기·저장·공유를 선택합니다.
화면을 꺼도 사용자 활성 런타임은 CPU 잠금을 유지하므로 배터리를 사용합니다.
작업 종료 후 작업 환경의 백엔드 중단으로 해제할 수 있습니다.

확인 범위와 남은 작업은 PRERELEASE-4-VALIDATION.md를 따릅니다.
전용 정식 서명, 자체 Preroot 전체 구현, dnfast의 일반 에이전트 실행 경로는 아직 완료되지 않았습니다.
dnfast 진단 성공은 제품 통합 또는 dnf5 대비 성능 우위를 뜻하지 않습니다.
